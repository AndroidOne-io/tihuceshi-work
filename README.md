# 鹈鹕测试剪辑项目

包含口播粗剪、分镜双轨工程、剪辑素材、来源资料、审片页面和剪辑风格参考。

## 文件说明

- `分镜素材工程/`：可继续编辑的 FCPXML 工程、素材、时间轴清单、工程 JSON 和浏览器双轨预览。
- `口播粗剪.mp4`：供仓库保存与预览的压缩口播视频。
- `口播粗剪.fcpxml`：原口播剪辑记录，依赖原始 `口播2.mp4`，该源文件不在本次提交目录内。
- `口播与素材对应文档.docx`、`逐字稿.txt`：内容与分镜资料。
- `审片.html`：口播审片页面。
- `剪辑风格参考/`：三个参考视频。

## 预览

安装 Python 3，在仓库根目录运行：

```sh
python3 分镜素材工程/制作资料/预览服务.py
```

浏览器打开 <http://127.0.0.1:8876/双轨预览.html>。
更多操作见 [分镜素材工程使用说明](分镜素材工程/使用说明.md)。

## 在剪辑软件中使用

`分镜素材工程/鹈鹕测试_分镜双轨.fcpxml` 为 30 fps、3840×2160 双轨时间轴。
FCPXML 保存了原制作机器的绝对素材路径，下载到其他位置后需要重新链接素材。
也可以安装 `ffmpeg`（包含 `ffprobe`），在 `分镜素材工程/` 目录运行以下命令，按当前目录重新生成素材路径与媒体参数：

```sh
python3 制作资料/交付工程.py
```

修改 `工程.json` 后，可运行 `python3 制作资料/更新预览.py` 刷新 HTML 内嵌的工程数据。
部分制作资料是原制作过程的记录，包含旧路径与来源资源 ID；重新下载来源素材还取决于原平台的访问权限。

## 仓库中的压缩素材

原口播粗剪约 492 MB，为 3840×2160、30 fps。为便于 GitHub 保存，提交副本使用 H.264、1920×1080、30 fps；音频直接复制，未重新编码，时长与剪辑内容保持一致。
根目录与 `分镜素材工程/` 中的 `口播粗剪.mp4` 使用同一压缩版本。
原目录中的 4K 文件及其他原始资料均保留，仓库版本适合预览和继续编排；需要原画质交付时请重新链接本地原件。
此处只压缩已有素材，没有新增合成成片。
