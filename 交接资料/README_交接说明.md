# 交接说明：小Lin说风格剪辑（鹈鹕测试项目沉淀）

给新对话的 Claude：这是上一个对话里为「AI阿亮」剪辑《鹈鹕测试》时积累的全部分析和规矩。**先读完本文件再动手**，不需要再逐帧看参考视频。

## 一、用户的硬性规矩（违反过、被严厉批评过）

1. **严禁画面上出现描述性文字、小字卡片、小标签**。包括：素材上的说明标签、小数据牌、多行文字卡、主播名片、栏目小标签、图表坐标轴/档位名、徽章里的英文小字副标题、提示词下面的中文翻译。手机上看不清的字一律不要。
2. 画面上的字只允许三种：**字幕**、**徽章/角色里的名字**、**单独出场的大标题**。
3. **大标题必须单独出现**（不和主播、不和素材叠在一起），用好的字体 + 动效 + 音效。不能压在人脸或素材正中。
4. **黄色漫画字**只用于人物外号，不用来表达观点。
5. 卡片只有**大卡片**，没有小卡片。
6. 背景**不能是纯黑或纯色平涂**，要有层次。
7. 截图、录屏**必须加工**：铺满、倾斜透视、甩镜进场、其余变淡只留重点、高亮扫过；不能原样小小地放中间，不能停太久，讲完就走。
8. 素材要裁掉自带字幕、水印、黑边、白屏空白、标签。
9. 外号字不能压在图上看不清：放在徽章两侧空处，主体抠图放下半部。
10. 用户要**一段一段交付**，有问题指出后，后面每段都要记得改。
11. 用中文交流。

## 二、小Lin说风格的精华（详见文件夹 2 和两份 Claude 文档）

- **角色徽章**：故事里每个人、每家公司都做成圆形徽章，全片反复登场；人物徽章两侧写书法外号（大卫、姐姐、老爹）。
- **反复回来的舞台**：同一张信息图出现多次，每次状态变化（变灰、盖章、变色、汇合）。
- **大字只在口播停顿时单独出现**：三种——银色金属字（最大收购案，上下各一行小字前提/英文）、粗毛笔飞白字（大道至简、文娱帝国，人物压字中间、可带故障闪）、数字（$810亿）。
- **截图处理**：铺满 → 透视倾斜 → 甩镜模糊进场 → 其余变淡 → 重点句高亮扫过 + 中文翻译（她有翻译，但用户不要小字，慎用）→ 人物侧边带渐变压入。
- **图表**：平放进场 → 倾斜成透视 → 大数字砸上 → 镜头推到重点。
- **背景**：深蓝灰 #151A25–#1A1F2C 或深紫，叠同心圆、网格、布纹，或垫压暗的相关大图（人物照片加网点）。
- **徽章**：半透明磨砂玻璃，细亮边，文字浅色半透明，选中亮其余灰。
- **节奏（实测）**：主播全屏只占 29%，单次中位 4.2 秒；画面平均每 1.3 秒有变化（每分钟 47 次）；不动的最长约 8 秒；语速 371 字/分；口播中每分钟 2–3 个 1 秒以上停顿。
- **音乐（实测，音源分离后）**：口播一停音乐抬高 15–25 dB 配重击；每分钟约 7 次低频冲击，对齐大字/盖章/数字；重击前音乐常完全停一下；按段落换曲；整片 -14 LUFS。

## 三、我们自己的风格「鹈鹕考场」（v4，用户已认可方向）

- 主色：夜蓝黑底，**鹈鹕橙** #FF8A2A 标志色，**电光青** #4ED6E8 辅色，**红笔红** #E84034 批改。
- 背景：矢量绘图网格（点阵 + 带锚点/控制柄的贝塞尔曲线）+ 橙青光晕。
- 徽章：半透明玻璃 + 橙色「选中框」（四角锚点方块）。
- 角色徽章：深色圆盘 + 抠图主体在下半部 + 外号大字（杨任东竹石体）在两侧。
- 结论用**红笔批改**：画圈、打叉、0分、「交白卷」印章。
- 大标题：金属拉丝（优设标题黑）+ 扫光 + 微光，背景橙青粒子隧道 + 模糊大字景深；或粗毛笔（庞门正道粗书体）+ 网点化素材背景 + 故障闪进场。
- 字幕：得意黑斜体白字细黑边，底部居中。

## 五、代码说明（Python + OpenCV + PIL + ffmpeg）

- `own.py` 背景、徽章、红笔、画中画、抠图（u2net_human_seg）；`own2.py` 金属标题/扫光/微光、毛笔标题、故障、粒子隧道、网点背景、角色徽章、通用抠图（isnet-general-use）。
- `style3.py` 字体与通用文字、贴纸、印章、字幕；`sample.py` 第1段（0–49秒）时间线；`v4.py` 整片时间线（含停顿插入表 INSERTS 和时间映射 T/N），按段渲染：`python3 v4.py video out.mp4 起 止`。
- `mix.py` 按 cue 表混音（人声分段、音乐分段+闪避+停顿抬升、真实音效对齐峰值、整片 -14 LUFS）；`cues.py` 生成整片 cue 表。
- 依赖资源需重新下载（容器是临时的）：
  - 字体：已放在 7_字体；来源 GitHub `wordshub/free-font`（优设标题黑、庞门正道粗书体、杨任东竹石体-Heavy）、`atelier-anchor/smiley-sans`（得意黑）、`google/fonts` ofl/mashanzheng、bebasneue。
  - 抠图模型：`github.com/danielgatis/rembg/releases/download/v0.0.0/` 下 `u2net_human_seg.onnx`、`isnet-general-use.onnx`。
  - 语音识别：`k2-fsa/sherpa-onnx` v1.13.8 linux-x64-static + `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`；音源分离 `spleeter-2stems-fp16`（按 60 秒分段跑，否则内存溢出）。
  - 素材仓库：`aliang2052/tihuceshi`（口播、分镜素材）、`aliang2052/Tempsucai` materials/audio/音乐素材（21 首配乐 + 7 个音效）。
- 网络只能访问 GitHub，pip/HuggingFace 不通。
