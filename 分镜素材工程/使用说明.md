## 预览和继续编辑

当前已开启本地预览： http://127.0.0.1:8876/双轨预览.html

以后若本地服务已关闭，在此目录运行：

```sh
python3 制作资料/预览服务.py
```

再打开上面的地址。也可直接尝试打开 HTML 文件。
在预览页修改后，将下载的工程 JSON 替换本目录 `工程.json`，再运行 `python3 制作资料/交付工程.py` 更新 FCPXML。预览 HTML 使用嵌入数据，更新 JSON 后需运行 `python3 制作资料/更新预览.py`。
工程使用当前素材的绝对路径。搬动文件夹后，可运行交付工程脚本重新生成路径，或在剪辑软件内重新链接素材。
