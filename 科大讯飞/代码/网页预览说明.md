# 工程网页预览

本机地址：http://127.0.0.1:8776

## 新机器运行

先拉取 `xunfei-ai4s-edit_codex` 分支及 Git LFS 素材，安装 FFmpeg、Python 3，以及 `numpy opencv-python pillow`。字体和音乐使用仓库中的相对路径。

在仓库根目录创建虚拟环境并安装依赖：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install numpy opencv-python pillow
cd 科大讯飞/代码
../../.venv/bin/python preview_server.py --prepare-audio
```

`--prepare-audio` 只生成网页播放需要的 WAV 混音，不编码视频。混音、成片及检查文件均被 Git 忽略，克隆后需要本地生成。生成完成后打开上述地址。之后可不带该参数启动。

macOS 也可双击 `启动网页预览.command`。它优先使用仓库 `.venv`，兼容现有 `.venv-render`，也可用 `KX_PYTHON` 指定解释器；服务已运行时直接打开网页。

## 操作

- 播放 / 暂停：空格键；逐帧查看：左右方向键。
- 修改点按钮根据当前时间线自动定位，包含换曲、复杂化工和结尾。
- 修改画面后点击“载入最新画面修改”；声音或时间线修改后，需要停止服务并用 `--prepare-audio` 重新启动。
- 预览目标 24 帧/秒，成片导出仍为 30 帧/秒。
- 暂停显示 1920×1080 PNG；播放使用 960×540 JPEG，按机器速度刷新，可能跳帧；页面显示实际刷新速度。
- 画面与导出共用 `full.py` 的 `frame(t)`，播放声音来自 `成片输出/节奏声音调整/win_audio.wav`。
- 当前修订：缩短留白、部分长口播轻微提速、21 处音效、7 段配乐连续交接、取消片尾定格。

仅监听本机，不向外网发布素材。手动启动时需保持终端运行；关闭进程后网页不可用。
